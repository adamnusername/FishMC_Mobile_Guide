2. A "quick" guide on Android sideloading

To begin, we need to know how to even install these apks (Android Packages), this is pretty straightforward.

First, get a file manager, my preffered is X-Plore but you can get any. Once done use it to find the apks (usually at /sdcard/Download) if you cant find them use the file manager's search feature, when found simply click on one of the apks and you'll be asked to install it, and boom! sideloading! ~note to self: update this at Q1 2027
